以下是类脑处理核**配置帧**和**测试帧**（1/2/3/4型）的详细数据结构描述，旨在帮助Code Agent理解并生成相应的数据帧。

所有帧的基础物理链路宽度为 **64 bits**。配置帧和测试帧采用**数据包协议**（Packet Protocol），由一个**起始帧**（Header Frame）和紧随其后的若干个**数据帧**（Data Frames）组成。

---

### 一、通用头部结构 (起始帧)
配置帧和测试帧的起始帧结构相同，均为64 bits。区别在于`帧类型标志位 `和` 子类型标志位`的值，以及包类型标识、地址/保留位、数据包数目等字段中部分位的定义。

| 位域范围 | 位宽 | 名称 | 说明 |
| :--- | :--- | :--- | :--- |
| **[63:62]** | 2 bits | **帧类型标志位** | **0x00**: 配置帧**0x01**: 测试帧 |
| **[61:60]** | 2 bits | **子类型标志位** | 决定是哪种配置/测试对象 (见下文各类型定义) |
| **[59:54]** | 6 bits | **Core_XY** | 目标Core的相对XY地址 |
| **[53:48]** | 6 bits | **Core_X** | 目标Core的相对X地址 |
| **[47:42]** | 6 bits | **Core_Y** | 目标Core的相对Y地址 |
| **[41:36]** | 6 bits | **Copy_XY** | 复制位XY地址 (Multicast用) |
| **[35:30]** | 6 bits | **Copy_X** | 复制位X地址 |
| **[29:24]** | 6 bits | **Copy_Y** | 复制位Y地址 |
| **[23]** | 1 bit | **包类型标识** | **配置帧**: 固定为 `1'b0`**测试帧**: `1'b1` (RV请求), `1'b0` (处理核响应) |
| **[22:14]** | 9 bits | **地址/保留位** | 根据子类型不同，定义为SRAM起始地址或保留位 (Reserved) |
| **[13:0]** | 14 bits | **数据包数目** | 指示紧随起始帧之后的数据帧数量 (N) |

**后续数据帧结构：**
起始帧之后，连续传输 **N** 个数据帧。每个数据帧仅包含 **64 bits 有效载荷 (LOAD)**，无额外头部。
*   **数据帧内容**: `[63:0]` 配置数据或测试响应的数据。测试请求没有后续数据帧。

### 二、配置帧 (Configuration Frames)
**帧类型标志位 = `0x00`**

#### 1. 配置帧 1型：Core参数配置 (CORE)
用于配置处理核的核心参数（如模式、位宽、时间片等）。
*   **子类型标志位 [61:60]**: `0x00`
*   **起始帧 [22:14]**: `Reserved` (保留)
*   **起始帧 [13:0]**: 数据包数目 (固定为 **3**，因为Core参数共192 bits，需3帧64 bits传输)
*   **数据帧内容顺序**:
    *   **第1帧**: `SNN_ANN`, `max_pooling`, ..., `test_core_y[5:4]` (共64 bits)
    *   **第2帧**: `test_core_y[3:0]`, `global_send`, ..., `width_cycle` (共64 bits)
    *   **第3帧**: `tick_start`, `tick_duration`, `tick_initial` (共64 bits)
    *   *(注：具体参数位定义参考文档2.3.1节)*
    *   *(注：配置帧 1型的数据帧内容全部由host工具链生成，RV只负责转发完整的64bit数据给离线核)*

#### 2. 配置帧 2型：激活函数 LUT SRAM配置
用于配置激活函数查找表 (256×32 和 256×8)。
*   **子类型标志位 [61:60]**: `0x01`
*   **起始帧 [22:14]**: **SRAM起始地址** (通常从0开始)
*   **起始帧 [13:0]**: 数据包数目 (全量配置需 **256** 帧)
*   **数据帧内容格式**:
    *   每帧对应一个RAM地址索引。
    *   **结构**: `24'd0` (高24位补0) + `RAM_0[i]` (8 bits) + `RAM_1[i]` (32 bits, 实际占用低32位中的部分，文档描述为RAM_0和RAM_1组合，总有效数据40bits，高24位填0凑齐64bits)。
    *   **顺序**: 从地址0到255依次发送。
    *   *(注：配置帧 2型的数据帧内容全部由host工具链生成，RV只负责转发完整的64bit数据给离线核)*

#### 3. 配置帧 3型：Neuron参数 SRAM配置
用于配置神经元参数和权重 (4096×128)。
*   **子类型标志位 [61:60]**: `0x10` (二进制 10)
*   **起始帧 [22:14]**: **SRAM起始地址 ÷ 8** (地址对齐)
*   **起始帧 [13:0]**: 数据包数目 (全量配置需 **8192** 帧)
*   **数据帧内容格式**:
    *   每个神经元参数占128 bits，需拆分为2帧传输。
    *   **奇数帧 (第1, 3...)**: `RAM[Addr][63:0]` (低64 bits)
    *   **偶数帧 (第2, 4...)**: `RAM[Addr][127:64]` (高64 bits)
    *   **顺序**: 从LSB开始，先传低64位，再传高64位，依次递增地址。
    *   *(注：配置帧 3型的数据帧内容全部由host工具链生成，RV只负责转发完整的64bit数据给离线核)*

#### 4. 配置帧 4型：Input缓存 SRAM配置
用于配置Input缓存 (256×512)。
*   **子类型标志位 [61:60]**: `0x11` (二进制 11)
*   **起始帧 [22:14]**: **SRAM起始地址**
*   **起始帧 [13:0]**: 数据包数目 (全量配置需 **2048** 帧)
*   **数据帧内容格式**:
    *   每个Input参数占512 bits，需拆分为8帧传输。
    *   **顺序**: 从LSB开始，依次发送 `RAM[Addr][63:0]`, `RAM[Addr][127:64]`, ..., `RAM[Addr][511:448]`。
    *   完成一个地址的8帧后，地址+1，继续下一组8帧。
    *   *(注：配置帧 4型的数据帧内容全部由host工具链生成，RV只负责转发完整的64bit数据给离线核)*

### 三、测试帧 (Test Frames)
**帧类型标志位 = `0x01`**
测试帧分为**请求帧**（发起读取请求）和**响应帧**（芯片返回数据）。

#### 通用规则：
*   **请求帧 (RV请求)**: 起始帧 **[23]位 = `1'b1`**。后续通常不跟数据帧（或跟少量控制数据，视具体实现，文档主要强调起始帧作为请求）。
*   **响应帧 (处理核响应)**: 起始帧 **[23]位 = `1'b0`**。起始帧后紧跟 **N** 个数据帧，包含读出的数据。数据内容与对应的配置帧完全一致。

#### 1. 测试帧 1型：Core参数测试
*   **子类型标志位 [61:60]**: `0x00`
*   **请求帧**: [23]=1, [22:14]=Reserved, [13:0]=请求包数目(通常为3)。
*   **响应帧**: [23]=0, 后续3个数据帧内容与**配置帧1型**的顺序和格式完全一致。

#### 2. 测试帧 2型：LUT SRAM测试
*   **子类型标志位 [61:60]**: `0x01`
*   **请求帧**: [23]=1, [22:14]=SRAM起始地址, [13:0]=请求包数目。
*   **响应帧**: [23]=0, 后续数据帧内容与**配置帧2型**一致 (`24'd0` + `RAM_0` + `RAM_1`)。

#### 3. 测试帧 3型：Neuron SRAM测试
*   **子类型标志位 [61:60]**: `0x10`
*   **请求帧**: [23]=1, [22:14]=SRAM起始地址÷8, [13:0]=请求包数目。
*   **响应帧**: [23]=0, 后续数据帧内容与**配置帧3型**一致 (每地址2帧，先低后高)。

#### 4. 测试帧 4型：Input SRAM测试
*   **子类型标志位 [61:60]**: `0x11`
*   **请求帧**: [23]=1, [22:14]=SRAM起始地址, [13:0]=请求包数目。
*   **响应帧**: [23]=0, 后续数据帧内容与**配置帧4型**一致 (每地址8帧，从LSB到MSB)。

### 给 Code Agent 的开发建议总结：
1.  **构建起始帧**: 根据操作类型（配置/测试）和目标模块（Core/LUT/Neuron/Input），设置 `[63:60]`。填入目标坐标 `[59:24]`。
2.  **设置负载控制**:
    *   若是**配置**，`[23]` 置 0，计算所需数据帧总数填入 `[13:0]`，并在 `[22:14]` 填入对应的起始地址（注意Neuron类型需除以8）。
    *   若是**测试请求**，`[23]` 置 1。
    *   若是**测试响应解析**，期待 `[23]` 为 0，并根据 `[13:0]` 接收后续数据。
3.  **连续性**: 一旦发送起始帧，必须连续发送完指定数量的数据帧，中间不能插入其他类型帧（如工作帧），以免破坏路由节点的计数器逻辑。（这个规则硬件没有规定，但软件先考虑遵守规定）。
