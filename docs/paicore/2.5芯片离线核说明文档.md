## 2.2.3 工作帧
工作帧用于芯片工作模式下的数据传输，包括普通数据帧和膜电平帧，其工作帧帧头固定为 `0b10`，负载（LOAD）区域均为 24bits。
### 工作帧1型和2型的通用数据帧格式
工作帧1型和2型的通用数据帧格式如下：
| 字段            | 位宽  | 位置    | 描述/值                              |
| :-------------- | :---- | :------ | :----------------------------------- |
| 帧头             | 4bits | [63:60] |                                      |
| 帧头 - 工作帧帧头     | 2bits | [63:62] | `0b10`                               |
| 帧头 - 1型还是2型     | 1bit  | [61]    | `0b0` = 1型，`0b1` = 2型              |
| 帧头 - Time Step [7] | 1bit  | [60]    | `0b0`                                |
| Core_XY         | 6bits | [59:54] | XY方向Core相对地址                   |
| Core_X          | 6bits | [53:48] | X方向Core相对地址                    |
| Core_Y          | 6bits | [47:42] | Y方向Core相对地址                    |
| Copy_XY         | 6bits | [41:36] | XY方向复制位地址                     |
| Copy_X          | 6bits | [35:30] | X方向复制位地址                      |
| Copy_Y          | 6bits | [29:24] | Y方向复制位地址                      |
| LOAD         | 24bits | [23:0]  | LOAD                             |
| LOAD - Time Step [6:0] | 7bits | [23:13] | TimeStep（与Axon地址位宽按比例分配） |
| LOAD - Axon 地址       | 9bits | [16:8]  | Axon地址（与TimeStep位宽按比例分配） |
| LOAD - Data Part        | 8bits | [7:0]   | 工作数据                             |
工作帧1型和2型的区别在于1. 帧头的第61位，1型为 `0b0`，2型为 `0b1`，2. Data Part工作数据的内容和传输方式不同。
### 工作帧1型（普通数据帧）
普通数据帧携带的数据 `Data` 最大为 8-bit 无符号数或有符号数。

> TimeStep和Axon地址的位宽可以根据LCN设置变化，可取的比例为 `8:9`、`7:10`、`6:11`、`5:12`、`4:13`、`3:14`、`2:15`、`1:16`。
> 此数据帧携带的数据 Data 最大为 8-bit 无符号数或有符号数。
| 顺序                        | Data Part [7:0] | 
| :---                        | :---            | 
| 第1帧                       | Data[7:0]        | 
### 工作帧2型（膜电平帧）
膜电平为32bits，此数据帧每次携带8bits数据，因此需连续4帧传输膜电平，从参数的LSB开始传输。

> TimeStep和Axon地址的位宽可以根据LCN设置变化，可取的比例为 `8:9`、`7:10`、`6:11`、`5:12`、`4:13`、`3:14`、`2:15`、`1:16`。
> 膜电平为 32 bits，此数据帧每次携带 8 bits 数据，因此需 4 帧传输膜电平，从参数的 LSB 开始传输。
| 顺序                        | Data Part [7:0] | 
| :---                        | :---            | 
| 第1帧                       | Vjt[7:0]        | 
| 第2帧                       | Vjt[15:8]       | 
| 第3帧                       | Vjt[23:16]      | 
| 第4帧                       | Vjt[31:24]      |

## 2.2.4 控制帧
控制帧用于控制和监控处理核工作状态。包含同步帧、初始化帧和完成帧三种类型，其控制帧帧头固定为 `0b11`，负载（LOAD）区域均为 24bits。
### 控制帧1型和2型和3型的通用数据帧格式
| 字段            | 位宽  | 位置    | 描述/值                              |
| :-------------- | :---- | :------ | :----------------------------------- |
| 帧头             | 4bits | [63:60] |                                      |
| 帧头 - 工作帧帧头     | 2bits | [63:62] | `0b10`                               |
| 帧头 - 1型还是2型还是3型   | 2bit  | [61:60]  | `0b00` = 1型，`0b01` = 2型，`0b10` = 3型              |
| Core_XY         | 6bits | [59:54] | XY方向Core相对地址                   |
| Core_X          | 6bits | [53:48] | X方向Core相对地址                    |
| Core_Y          | 6bits | [47:42] | Y方向Core相对地址                    |
| Copy_XY         | 6bits | [41:36] | XY方向复制位地址                     |
| Copy_X          | 6bits | [35:30] | X方向复制位地址                      |
| Copy_Y          | 6bits | [29:24] | Y方向复制位地址                      |
| LOAD         | 24bits | [23:0]  | LOAD                             |
控制帧1型和2型和3型的区别在于1. 帧头的第61:60位，1型为 `0b00`，2型为 `0b01`，3型为 `0b10`，2. Data Part控制数据不同。
### 控制帧1型（同步帧）
同步帧由调度核发出，用于驱动处理核开始工作并指定运行的步长 `TimeStep`。
| 顺序                        | LOAD [23:0] |
| :---                        | :---        |
| 第1帧                       | 执行TimeStep数目 |
### 控制帧2型（初始化帧）
初始化帧由调度核发出，用于重置处理核的内部状态。
| 顺序                        | LOAD [23:0] |
| :---                        | :---        |
| 第1帧                       | reserverd |
### 控制帧3型（完成帧）
完成帧由处理核在计算结束后主动上报，携带对应的线程序号，便于上层调度系统追踪多线程任务的完成情况。
| 顺序                        | LOAD [23:0] |
| :---                        | :---        |
| 第1帧                       | 线程序号 |
## Core_XY、Core_X、Core_Y、Copy_XY、Copy_X、Copy_Y的说明
Core_XY、Core_X、Core_Y、Copy_XY、Copy_X、Copy_Y字段用于指定数据传输的目标处理核的相对地址和复制位地址。Core_XY、Core_X、Core_Y表示目标处理核的相对地址，Copy_XY、Copy_X、Copy_Y用于广播数据，表示该数据包被路由到芯片中的Core_XY、Core_X、Core_Y地址后，是否需要继续被复制到相邻的处理核上。
NOC处理相对地址和复制位地址的时候，会改写数据包头中的Core_XY、Core_X、Core_Y、Copy_XY、Copy_X、Copy_Y字段，直到数据包被路由到目标处理核的地址上，或者被复制到相邻的处理核上。需要注意的是，在riscv的接收过程中，这几个字段经过NOC的传输后，肯定已经被改写为了0，不能标识是哪个处理核发来的数据了。因此，在riscv接收数据的时候，不能通过Core_XY、Core_X、Core_Y、Copy_XY、Copy_X、Copy_Y字段来判断是哪个处理核发来的数据，而应该通过完成帧的线程序号来判断是哪个处理核发来的数据。

## 总结
1. **功能定位**：工作帧和控制帧均采用**单帧格式**（区别于配置/测试帧的数据包格式），这主要是为了兼顾有效数据比例和系统吞吐率。
2. **工作帧特性**：
   * 核心作用是传递工作模式下的运行数据。
   * 具有极高的灵活性，其内部 `TimeStep` 与 `Axon地址` 的位宽比例（共16bits）可根据核参数中的 `LCN` 设置在 8:9 到 1:16 之间动态调整。
   * 支持两类数据：单帧即可传输的 8-bit 常规工作数据，以及需要连续 4 帧拼装的 32-bit 膜电平数据。
3. **控制帧特性**：
   * 核心作用是实现多核协同的生命周期管理。
   * **同步帧**用于驱动核开始工作并指定运行的步长；
   * **初始化帧**用于重置核的内部状态；
   * **完成帧**由处理核在计算结束后主动上报，携带对应的线程序号，便于上层调度系统追踪多线程任务的完成情况。
